# d01 – Šablóna (Neon)

Ukážkový dizajn, ktorý sa kopíruje pri tvorbe nového dizajnu. Postup je v `docs/DESIGNS.md`.

- `design.json`: názov, paleta, fonty, pozadie menu, motion a farby mapy. Komentáre sú v kľúčoch `_comment`.
- `theme.tres`: Godot Theme. Komentáre sú v riadkoch `;`.
- `menu_bg.tres`: pozadie hlavného menu.
- `LICENSES.md`: licencie fontov a pozadí.
