# Návrh herných ikon

Osem nových pixelových ikon. Každá má 128×128 px a priehľadné pozadie. Štýl je hrubý obrys a ploché farby, aby sedeli k súčasným ikonám firiem, ale sú to nové kresby.

Do hry zatiaľ nejdú. Súbory v `assets/icons/` ostávajú. Priečinok má `.gdignore`, takže ich Godot pri otvorení projektu neimportuje.

| Súbor | Význam |
| --- | --- |
| `peniaze.png` | hotovosť |
| `lod.png` | lode |
| `banka.png` | banka |
| `tovaren.png` | továreň / priemysel |
| `vyskum.png` | výskum |
| `noviny.png` | noviny |
| `mapa.png` | mapa |
| `pauza.png` | pauza |

Keď povieš, ktoré berieš, dajú sa zmenšiť na 32×32 a napojiť na hornú lištu. Dovtedy sa rozhranie nemení.
