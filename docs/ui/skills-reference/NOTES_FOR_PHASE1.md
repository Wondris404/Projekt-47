# Poznámky pre fázu 1 — prémiové tlačidlá (Paradox-like)

Vlastné poznámky z SKILL.md (frontend-design, canvas-design, theme-factory, godot-ui-theming, godot-ui-containers, godot-tweening). Nie sú súčasťou upstream diela. Platí pre Godot tlačidlá: téma, 9-patch, typografia, žiadna generická AI estetika, kontajnery, hover tweeny.

- Jeden zdieľaný Theme na koreni (Project Settings → GUI → Theme, alebo `theme` na root Control). Globálny vzhľad nepatří do `add_theme_*_override` ani do stoviek `StyleBoxFlat.new()` v `_ready`. Dieťa s vlastným `theme` preruší kaskádu; po výmene témy zmazať staré override.
- Varianty tlačidla (primary / ghost / danger) sú `theme_type_variation` s base type `Button`. Overridnúť len rozdiel, neforkovať Button scény kvôli farbe.
- Prémiový rám, ktorý sa nesmie rozmazať pri resize: `StyleBoxTexture` alebo `NinePatchRect`, nie naťahovaná bitmapa. `StyleBoxFlat` len na jednoduchý chrome: `corner_radius_all`, `anti_aliasing`, vyšší `corner_detail`. Klikacia plocha ide cez `content_margin_*` (alebo veľkosť Controlu), nie cez `expand_margin_*` — ten len zväčší kresbu.
- Zdieľaný StyleBox z Theme sa nemutuje. Runtime tint až po `duplicate()`. StyleBox neschovávať ako lokálnu premennú v `_draw()` a nemeniť Theme v `_process` / `_draw`. Farby z Theme palety (`get_color` / ThemeDB), nie natvrdo v každom boxe. Ikony ako Theme Icon + `AtlasTexture`; ostrý UI chrome bezstratovo.
- Focus nesmie byť holý `StyleBoxEmpty`. Gamepad a klávesnica potrebujú viditeľný stav (obrys alebo scale). High-contrast vetva: čistá čiernobiela a hrubší focus.
- Typografia: jedna rodina, alebo dve zreteľne odlišné. Nie systémový default a nie DejaVu z theme-factory presetov. Nie ALL-CAPS na každý label, nie jedno slovo v inej farbe/italic, nie `→` prilepené na text tlačidla. CTA v sentence case hovorí, čo sa stane („Uložiť“, nie „Submit“). Krátke riadky, font cez Theme `font_size` a `content_scale_factor`, nie scale celého Controlu. Text sa neprekrýva a má okraj.
- Žiadny generický AI look: krém `#F4F1EA` + serif + terracotta, čierna + acid green, rovnaký border-radius a tieň `rgba(0,0,0,.1)` na každej karte, tracked-out eyebrow, monospace na drobné labely, fade-and-slide na každú sekciu. Presety theme-factory (Ocean, Tech Innovation, …) sa neaplikujú naslepo. Paleta je 4–6 pomenovaných hexov tejto hry. Jeden odvážny prvok, zvyšok tichý; vyzerá to ako remeslo, nie šablóna.
- Najprv layout, potom skin. Tlačidlá sedia v `MarginContainer` / `HBox` / `VBox`. V kontajneri nenastavovať `position` ani `size` — prepíše ich `queue_sort`. Rozťahovanie je `size_flags` (`SIZE_EXPAND_FILL` nie je default) a `custom_minimum_size`. Tesný default `separation` overridenúť. Overlay má `mouse_filter` PASS alebo IGNORE, aby nezožral klik. Hlbšie ako ~10 vnorených kontajnerov nie.
- Hover je odpoveď na akciu, nie dekorácia na každej karte. Jeden `create_tween()` (nie `Tween.new()`), pred opakovaným hoverom `kill()`. Ease nie je lineárny: `EASE_OUT` + `TRANS_QUAD` alebo `EASE_IN_OUT` + `TRANS_CUBIC`. V kontajneri netweenovať `position`; ak má sused uhnúť, tween `custom_minimum_size`. Menu pri `time_scale == 0` potrebuje `set_ignore_time_scale(true)`. Nekonečný ping-pong loop nie je hover prémiového tlačidla.
